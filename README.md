# KinoKi

Android TV-სა და ტელეფონისთვის განკუთვნილი აპლიკაცია mykadri.tv-დან ფილმებისა და სერიალების მოსაძებნად და საყურებლად:
კატეგორიების ტაბები, ჟანრების ფილტრი, ძებნა, სერიალების გაშლა სეზონებად და ეპიზოდებად, ფავორიტები, ნახვის ისტორია
და დაკვრის გაგრძელება იმ ადგილიდან, სადაც შეწყვიტე.

ტელეფონზე დამკვრელი სრულ ეკრანზეა: სტატუს ბარი (საათი, Wi-Fi, ბატარეა) იმალება, ეკრანზე შეხებისას ბრუნდება და
რამდენიმე წამში ისევ ქრება.

## შესაძლებლობები

- კატეგორიების ტაბები, ჟანრების ფილტრი და ძებნა.
- სერიალები იშლება სეზონებად და ეპიზოდებად; ნახული ეპიზოდები მწვანედ აღინიშნება.
- დაკვრა აგრძელდება იქიდან, სადაც გაჩერდი (5 წამით უკან, რომ წინადადება არ დაკარგო).
- ფავორიტები: ფილმზე ან სერიალზე ხანგრძლივი დაჭერა (ტელეფონზე — თითის გაჩერება, პულტზე — OK-ის დაჭერა).
- ნახვის ისტორიის ტაბი.
- ერთი და იგივე APK ტელეფონსა და ტელევიზორზე. აპი თავად ცნობს, ტელევიზორია თუ ტელეფონი
  (`android.software.leanback` / `android.hardware.television` ნიშნებით), ამიტომ ცალკე ვერსია არ საჭიროა.
- ტელეფონიდან ფილმის ტელევიზორზე გადაგდება LAN-ით, Google Cast-ის გარეშე (იხ. ქვემოთ).

გვერდები იკითხება საიტიდან (scraping), ამიტომ საიტის HTML-ის ცვლილებამ შეიძლება ჩამონათვალი ან დაკვრა
გააფუჭოს (იხ. `Site.java`). თუ ლოკალური DNS საიტს ბლოკავს, აპი DNS-over-HTTPS-ზე გადადის.

## აწყობა

საჭიროა Android SDK (platform 35) და JDK 17+. შექმენი `local.properties` და ჩაწერე SDK-ის გზა:

```
sdk.dir=C\:/path/to/Android/Sdk
```

შემდეგ:

```
gradle assembleDebug
```

მზა APK: `app/build/outputs/apk/debug/app-debug.apk`.

## ტელეფონიდან ტელევიზორზე ჩართვა

ტელეფონზე ჩართე ფილმი და დააჭირე **ტელევიზორზე ▸** ღილაკს — ტელევიზორი იმავე სათაურს იმავე წამიდან გახსნის.
შემდეგ ტელეფონზე ჩნდება პულტი: პაუზა/გაგრძელება, ±30 წამი, ხმა +/−, დადუმება და გათიშვა. გათიშვისას დაკვრა
ტელეფონზე ბრუნდება იმ ადგილიდან, სადაც ტელევიზორმა შეწყვიტა.

სანამ დამკვრელი გახსნილია, ტელეფონი ქსელს პერიოდულად ამოწმებს, ამიტომ ქასთის ღილაკი მხოლოდ მაშინ ჩნდება, როცა
ქსელში ამავე აპლიკაციის მქონე ტელევიზორი პასუხობს. ღილაკი რამდენიმე წამში თავისით ქრება, რომ ვიდეოს არ ფარავდეს;
ეკრანზე შეხებით ისევ გამოჩნდება.

პულტის ხმის ღილაკები ცვლის ტელევიზორის საკუთარ media ხმას (იმავეს, რასაც ტელევიზორის პულტი). ტელეფონზე ნაჩვენები
პროცენტი ტელევიზორიდან იკითხება, ამიტომ ტელევიზორის პულტის გამოყენებისასაც სწორად განახლდება.

ორივე მოწყობილობას სჭირდება ერთი და იგივე აპლიკაციის ვერსია და ერთი და იმავე Wi-Fi ქსელი. Google Cast, Play Services
ან ცალკე receiver არ გამოიყენება: ტელეფონი ნაკადის მისამართსა და პოზიციას პირდაპირ უგზავნის ტელევიზორს LAN-ით, ამიტომ
მუშაობს scraped ნაკადებზეც.

1. ტელევიზორზე აპლიკაცია ერთხელ გახსენი — ეს რთავს `CastService`-ს, რომელიც ფონზე ტოვებს პატარა კონტროლის
   სერვერს (TCP 8477) და საძიებო პასუხისმგებელს (UDP 8478). ამის შემდეგ ქასთი ტელევიზორზე შეხების გარეშე მუშაობს.
2. ტელეფონი ტელევიზორს broadcast-ით პოულობს. თუ ვერ იპოვა (სტუმრების Wi-Fi client isolation-ით, ან სხვა ქვექსელი),
   ვიდეოზე ხანგრძლივად დააჭირე და ტელევიზორის IP მისამართი ხელით ჩაწერე.

იმ ტელევიზორზე ქასთი, რომლის აპლიკაცია ჩართვის შემდეგ არ შეხებია, ნიშნავს დამკვრელის ფონიდან გაშვებას. Android ამას
მხოლოდ „სხვა აპებზე გამოსახვის" ნებართვით უშვებს, რომელიც ერთხელ უნდა მიენიჭოს ADB-ით:

```
adb shell appops set com.dmegr.kinoki SYSTEM_ALERT_WINDOW allow
```

## პროტოკოლი

პროტოკოლი ჩვეულებრივი HTTP-ია LAN-ში, ავტორიზაციის გარეშე. ტელევიზორი (TCP 8477):

| გზა | მეთოდი | დანიშნულება |
|---|---|---|
| `/info` | GET | აპის სახელი, მოწყობილობის სახელი, პორტი |
| `/status` | GET | მიმდინარე სათაური, პოზიცია, ხანგრძლივობა, დაკვრა/პაუზა, ხმის დონე |
| `/play` | POST | ნაკადის URL, სათაური, watchKey, საწყისი პოზიცია |
| `/pause` `/resume` `/stop` | POST | პაუზა, გაგრძელება, გათიშვა |
| `/seek` | POST | პოზიციაზე გადასვლა |
| `/volume` | GET / POST | ხმის დონის წაკითხვა / `up`, `down`, `mute` |

ძებნა: UDP broadcast პორტ 8478-ზე `KINOKI_DISCOVER`-ით; ტელევიზორი პასუხობს `KINOKI_HERE|სახელი|8477`-ით.

ვინაიდან ავტორიზაცია არ არის, იმავე ქსელში მყოფს შეუძლია ნახოს მიმდინარე სათაური და მართოს დაკვრა. პროტოკოლი
სახლის ქსელისთვისაა განკუთვნილი და არა უცხო ან საჯარო ქსელისთვის.
